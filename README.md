# TOMATO — Food Ordering Web Application

TOMATO is a modern and responsive food-ordering web application built with an attractive UI and seamless functionality.  
Users can browse restaurants, explore menus, manage carts, and place orders effortlessly.  
This project demonstrates a complete full-stack implementation with scalable architecture and robust backend APIs.

---

## ✨ Features

- ✅ Beautiful & responsive UI/UX  
- ✅ Browse restaurants & menus  
- ✅ Add/remove items to cart  
- ✅ User authentication & authorization  
- ✅ Order creation & tracking  
- ✅ REST API (Node.js + Express)  
- ✅ Dual database support (PostgreSQL + MongoDB)  
- ✅ Prisma ORM integration  
- ✅ Modular project architecture

## 🚀 Getting Started

### ✅ Clone the repository
```bash
git clone https://github.com/yourusername/tomato.git
cd tomato
```
## Install dependencies
### Frontend
```bash
cd frontend
npm install
```
### Backend
```bash
cd backend
npm install
```
## Run the Application
### Start Backend
```bash
cd backend
npm start
```
### Start Frontend

```bash
cd frontend
npm run dev
```
### Environment Variables

#### Inside /backend, create a .env file:
```bash
DATABASE_URL=
MONGO_URL=
PORT=
JWT_SECRET=
```
